08 / OBS COMPUTER SETUP

Production machine setup

Full setup guide ↗
  1. Install a current OBS Studio release on the production PC.
  2. Create profile and scene collection named CR-24H-TACOMA-2027.
  3. Start with 1920×1080 at 30 fps; test encoder and upload capacity before finalizing.
  4. In OBS, open Tools → WebSocket Server Settings, enable the server and set a unique strong password. Keep port 4455 local only.
  5. Never port-forward 4455 or place OBS password, YouTube stream key or service-role key in GitHub, HTML, JavaScript or browser storage.
  6. Create the YouTube Live event and enter its stream key directly in OBS, never in this website.
  7. Record continuously to a dedicated fast drive. Prefer MKV; test one hour and calculate 24-hour storage plus at least 25% headroom.
  8. Use Ethernet, UPS, disable sleep/automatic restart, prepare backup internet and an alternate encoder recovery plan.
  9. Rehearse a private/unlisted stream, host handoff, source failure, reconnect and local recording playback.
STUDIO LIMITATION: This workspace reads event data and tracks browser-side preflight checks. It does not connect to OBS, switch scenes, admit remote guests, start/stop YouTube or verify encoder health. Web control remains disabled until the secure command service and local bridge are deployed.
SECURITY: Never put stream keys, OBS WebSocket passwords, bridge secrets or Supabase service-role keys in GitHub files, public HTML or browser storage.
