Reconcile uncertain delivery

For an Unknown record, first search Brevo transactional logs using the timeframe and message details. Never retry an unknown outcome until you have confirmed Brevo did not accept the message.

Important: “Mark as sent” updates the ledger and activity record. “Retry” only makes a confirmed-undelivered message eligible for the worker’s normal retry process; it does not send mail directly.

Access is checked by a server-side Hub admin allowlist on every request. The browser only uses the public Supabase key and the signed-in user's session; service-role and cron secrets are never sent to this page.
